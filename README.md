# Nitin's Expense Analysis

## 📊 Project Overview

**Nitin's Expense Analysis** is an Excel-based analytics project that analyses Nitin's personal expenses for **June** and across a **six-month period (January–June)**.

The objective is to understand where Nitin's money is being spent, identify major and recurring expense categories, analyse spending patterns, and suggest practical ways to increase monthly savings toward a scooter fund.

## 🎯 Problem Statement

Nitin earns **₹15,000 per month** and wants to save money to buy a scooter for his daily commute. However, he has been unable to save consistently.

This project uses expense data to answer:

- Which categories account for the highest expenses?
- Which items contribute most to those categories?
- How does spending change from month to month?
- Which categories repeatedly appear among the top expenses?
- Which expenses are more controllable?
- Where can spending be reduced without affecting essential needs?

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Bar Charts
- Pie/Doughnut Charts
- Line Charts
- Conditional Formatting / Data Bars
- Category-wise, item-wise and month-wise analysis

## 📁 Data Analysed

The project uses two datasets:

1. **June Expense Log** – detailed transaction-level data for June.
2. **Six-Month Expense Log** – expense data from January to June, grouped by month, category and item.

## 🔎 Methodology

### Part 1 — June Analysis

The June data was analysed using:

- Category-wise expense summaries
- Item-wise expense analysis
- Entertainment and Ticket & Bills breakdown
- Transaction frequency analysis
- Data bars for the highest and second-highest categories
- Summary of key June findings

### Part 2 — Six-Month Analysis

The January–June data was analysed using:

- Month-wise expense trends
- Category-wise six-month totals
- Top two expense categories for each month
- Movie and dining-out spending comparison
- Identification of recurring and one-time expenses
- Recommendations for increasing savings

## 📌 Key Findings

### June

| Finding | Result |
|---|---:|
| Total recorded expense | ₹13,560 |
| Highest category | Grocery — ₹4,690 |
| Second-highest category | Shopping — ₹3,500 |
| Entertainment + Shopping | ₹4,500 |
| Online food orders | 4 orders — ₹600 |
| Movie visits | 4 visits — ₹1,000 |
| Highest individual item | Tshirt and Jeans — ₹2,500 |

Grocery was the largest June category, while Shopping was the largest discretionary category. Vegetables were the largest individual grocery item at ₹1,690.

### Six-Month Analysis

| Category | Jan–Jun Total |
|---|---:|
| Grocery | ₹30,990 |
| Ticket and Bills | ₹16,040 |
| Entertainment | ₹12,000 |
| Shopping | ₹8,700 |
| Miscellaneous | ₹7,720 |
| Food | ₹4,940 |
| Doctor and Medicine | ₹4,000 |

The highest-spend month was **February — ₹15,620**, largely influenced by a **₹7,500 North Bengal trip**.

Grocery appeared among the top two expense categories in **5 of the 6 months**, showing that it is a recurring expense.

## 💡 Recommendations

Based on the analysis:

- Set a monthly limit for movies, shopping, dining out and online food.
- Plan large purchases instead of making them impulsively.
- Budget separately for large trips or one-time expenses.
- Continue prioritising essential expenses such as groceries and medicines.
- Review miscellaneous expenses individually.
- Reduce controllable expenses before cutting essential spending.

The project estimates that trimming entertainment, food delivery and impulse shopping could create approximately **₹1,000–₹1,500 of potential monthly savings**, based on the analysed spending patterns.

## 📈 Project Outcome

The analysis converts raw expense records into visual summaries and actionable insights. It demonstrates how Excel analytics can be used to identify spending patterns, compare categories, understand monthly trends and support data-based budgeting decisions.
